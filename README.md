# Visualisasi Struktur Organisasi PKN STAN

Repository ini berisi kode sumber untuk visualisasi data interaktif dari struktur organisasi Politeknik Keuangan Negara STAN (PKN STAN). Proyek ini dibuat untuk mempermudah pemahaman alur birokrasi, tata kerja, serta pembagian tugas jabatan di lingkungan kampus.

## 📌 Fitur Utama
* **Bagan Pohon (Tree Chart):** Visualisasi hierarki interaktif untuk melihat hubungan atasan dan bawahan secara langsung.
* **Kartu Kategori:** Pengelompokan jabatan berdasarkan kluster (Unsur Pimpinan, Program Studi, Unit Penunjang, dll).
* **Daftar Tabel:** Penyajian data seluruh jabatan dalam bentuk tabel yang rapi dan mudah dibaca.
* **Fitur Pencarian:** Mempermudah pencarian nama pejabat, gelar, atau posisi tertentu secara *real-time*.

## 🏛️ Landasan Struktur
Data dan hierarki yang digunakan dalam proyek ini disesuaikan dengan aturan resmi tata kerja perguruan tinggi vokasi di bawah Kementerian Keuangan RI, yaitu **PMK Nomor 160/PMK.01/2020**.

Struktur organisasi yang divisualisasikan mencakup:
1. **Unsur Pimpinan:** Direktur dan para Wakil Direktur.
2. **Organ Pertimbangan:** Senat Akademik dan Dewan Pertimbangan.
3. **Unsur Pengawas & Penjamin Mutu:** Satuan Pemeriksaan Intern (SPI) & Satuan Penjaminan Mutu (SPM).
4. **Pelaksana Akademik:** Pusat Penelitian dan Pengabdian kepada Masyarakat (PPPM) serta Program Studi (D-III & D-IV).
5. **Administrasi & Penunjang:** Bagian Administrasi Akademik & Kemahasiswaan, Bagian Keuangan & Umum, serta Unit Penunjang Teknis (Perpustakaan, SI, Bahasa, dll).
